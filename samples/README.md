# Integration guide

Base API is https://api.example.com/v1 and the sandbox is
https://sandbox.example.com/v1.

- Docs: https://docs.example.com/getting-started
- Status: https://status.example.com
- Support: mailto:support@example.com
- Mirror: ftp://mirror.example.com/pub/releases

Assets are served from https://cdn.example.com/assets and images from
https://cdn.example.com/images. Webhooks post to
https://hooks.example.com/v1/receive.
